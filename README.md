# rugender

Офлайн-определение пола по ФИО в русской записи. Рассчитан на реальный поток ФИО
по России и бывшему СССР: русские, украинские, белорусские, татарские, башкирские,
казахские, кыргызские, узбекские, таджикские, азербайджанские, армянские, грузинские,
северокавказские, прибалтийские ФИО, корейцы СНГ, а также китайские, вьетнамские,
европейские и арабские ФИО в русской транскрипции.

- **Без зависимостей и без сети**: чистый Python ≥ 3.9, словари внутри пакета (~3,5 МБ).
- **Объяснимый результат**: пол, правило-основание, уверенность и все сигналы.
- **Честное «не определено»**: если по ФИО пол не определить (Саша Пак, Черных), пакет
  не угадывает — значение по умолчанию выбирает приложение.
- **Детерминизм**: словари собираются воспроизводимо из открытых источников, тест сверяет
  данные пакета со сборкой.

## Установка

```bash
pip install git+https://github.com/alexblag023/rugender
```

## Использование

```python
from rugender import detect

detect("Иванова", "Мария", "Петровна").gender     # 'f'  (по отчеству)
detect("Мамедов", "Эльчин", "Гасан оглы").gender  # 'm'  (частица «оглы»)
detect("Нгуен", "Тхи Хоа").gender                 # 'f'  (вьетнамское среднее имя «Тхи»)
detect("Ван", "Сяомэй").gender                    # 'f'  (китайское имя; «Ван» — фамилия)
detect("Казлаускене").gender                      # 'f'  (литовская фамилия замужней)
detect("Пак", "Саша").gender                      # ''   (не определить)

v = detect("Иванова", "Никита")
v.gender, v.basis, v.confidence                   # ('m', 'name', 'low') — имя против фамилии
[(s.role, s.token, s.rule, s.weight) for s in v.evidence]
```

`detect(surname=None, name=None, patronymic=None) -> Verdict`. Любое поле может быть
пустым; ФИО целиком в одном поле разбирается («Иванова Мария Петровна», «Анна Ивановна
Смирнова»). Вход нормализуется: регистр, «ё», латинские двойники кириллических букв,
латиница целиком (Ivanova), инициалы, буквы казахской/таджикской/татарской кириллицы.

`Verdict`: `gender` — `m` | `f` | `''`; `basis` — правило, решившее исход (`patronymic`,
`particle`, `vn_middle`, `name`, `syllables`, `morpheme`, `name_suffix`, `surname_suffix`,
`surname_exact`, `none`); `confidence` — `high` | `medium` | `low`; `evidence` — сигналы.

## Как это работает

Каждая часть ФИО даёт сигналы с весом (плюс — женский, минус — мужской, 0 — пола не даёт):

1. **Отчество решает сразу**: «-ич» / «-вна, -чна, -шна»; тюркские частицы «оглы, улы,
   уулу, угли» / «кызы, гызы, кизи» — отдельным словом, через дефис или слитно;
   вьетнамское среднее имя «Тхи» (ж) / «Ван» (м).
2. **Имя**: словарь из 85 тыс. имён (±6); у китайских, вьетнамских и корейских ФИО —
   слоги имени (система Палладия для китайского: «Сяо+мэй»; ±2 за слог); морфемы
   тюркских и иранских имён (гуль-, -бек, -жон, -иддин; ±3); окончание имени по правилам
   Petrovich (±2).
3. **Фамилия**: самое длинное окончание (-ова/-ина/-ская ±4; литовские -ене/-айте, латышские
   -иньш/-иня ±3); двуполые группы (-ян, -швили, -дзе, -енко, -ук, -ич, -ых, Ким, Нгуен…) — 0.

Сумма |S| ≥ 2 — пол по знаку, иначе «не определено». Противоречие (женская фамилия при
мужском имени) не прячется: побеждает больший вес, уверенность — `low`.

## Качество

Корпусы — вымышленные ФИО (реальных людей нет), `tests/`:

- `corpus.tsv` — составлен вместе со словарями (завышен, служит регрессией);
- `corpus_blind.tsv` — независимый автор, не видевший словарей; по нему улучшались правила;
- `corpus_holdout.tsv` — второй независимый автор, пропорции потока должников ЖКХ по РФ;
  по нему ничего не настраивалось.

| `corpus_holdout.tsv`, 450 ФИО | точность на решённых | «не определено» | итог, если «не определено» = м | женщин с «м» |
|---|---|---|---|---|
| **rugender 0.1.0** | 99,8 % | 3,6 % | 97,6 % | 4,8 % |
| pytrovich 0.2.0 | 94,1 % | 14,0 % | 85,8 % | 26,1 % |

```bash
python scripts/evaluate.py --corpus tests/corpus_holdout.tsv --errors
```

Скорость: загрузка словарей ~1 с один раз на процесс, 10 000 определений ~0,4 с.

## Данные и их сборка

Словари `src/rugender/data/*.tsv` руками не правят: источники лежат в `data_src/`, сборка —

```bash
python scripts/build_data.py           # собрать
python scripts/build_data.py --check   # данные пакета совпадают со сборкой
```

Источники (подробно с лицензиями — [NOTICE.md](NOTICE.md), [data_src/README.md](data_src/README.md)):
ручные словари; правила Petrovich (MIT); ЗАГС Татарстана (CC BY 4.0); Бюро нацстатистики
Казахстана; ЗАГС Москвы (data.mos.ru); Латвия PMLP (CC0); Литва VLKK (CC BY 4.0);
Минюст Азербайджана (CC0); Wikidata (CC0). Латиница переводится в русскую запись при
сборке (`scripts/translit.py`). Обновление источников — `scripts/fetch_*.py` (нужен интернет).

Если два источника данных называют разный пол имени (Айман: у казахов женское, у татар
мужское), имя считается двуполым и пол решают отчество и фамилия.

## Ограничения

- Китайские имена из нейтральных слогов («Сяомин», «Пин») часто не определяются.
- Редкие женские имена на согласную вне словарей (эстонские, армянские) могут получить «м»
  по окончанию.
- Двуполые имена без отчества (Саша, Женя, Валя) при несклоняемой фамилии не определяются.
