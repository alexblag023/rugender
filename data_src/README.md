# Источники данных rugender

Сырые источники словарей определителя пола по ФИО (`src/rugender`). Данные пакета
(`src/rugender/data/*.tsv`) собирает `scripts/build_data.py`; руками их не правят.
Выгрузки из открытых данных запускаются на машине разработчика (нужен интернет), сервер
в интернет не ходит. В запросах к источникам персональных данных нет.

| Каталог | Источник | Лицензия | Что берём | Выгрузка |
|---|---|---|---|---|
| `manual/` | составлено для rugender | MIT | имена-ловушки, имена народов, слоги, морфемы, окончания фамилий, частицы отчеств | вручную |
| `petrovich/` | [petrovich-rules](https://github.com/petrovich/petrovich-rules), © 2013 Petrovich Developers | MIT (`petrovich/LICENSE`) | окончания имён/фамилий/отчеств, исключения | копия |
| `tatarstan/` | Управление ЗАГС КМ РТ, «Татарско-русский словарь личных имён, отчеств и фамилий» | CC BY 4.0 | имя (рус.), пол, имя (тат.) | `scripts/fetch_tatarstan_names.py` |
| `moscow/` | Управление ЗАГС Москвы, «Популярные имена новорождённых» (data.mos.ru) | открытые данные, со ссылкой на Портал открытых данных ([условия](https://data.mos.ru/terms)) | имя, число детей по полу | `scripts/fetch_moscow_names.py` |
| `kazakhstan/` | Бюро национальной статистики АСПиР РК, сервис «Популярные имена» | свободно со ссылкой на источник | имя, число носителей по полу (все народы РК) | `scripts/fetch_central_asia_names.py` |
| `azerbaijan/` | Минюст Азербайджана, «Azərbaycan adları» (opendata.az) | CC0 | имя (латиница), пол | `scripts/fetch_central_asia_names.py` |
| `latvia/` | PMLP Латвии, «Personu vārdi» (data.gov.lv) | CC0 | имя (латиница), число носителей по полу | `scripts/fetch_baltic_names.py` |
| `lithuania/` | VLKK Литвы, «Vardų lingvistiniai duomenys» (data.gov.lt #2664) | CC BY 4.0 | имя (латиница), пол | `scripts/fetch_baltic_names.py` |
| `wikidata_people/` | Wikidata: люди (Q5) с гражданством СССР, Российской империи и 15 республик | CC0 | имя (рус. метка), число мужчин и женщин | `scripts/fetch_wikidata_people_names.py` |
| `wikidata/` | Wikidata: классы «мужское / женское / унисекс-имя» | CC0 | имя (рус. метка), пол | `scripts/fetch_wikidata_names.py` |

Латиница переводится в русскую запись при сборке (`scripts/translit.py`):
латышский, литовский, азербайджанский; казахская кириллица — нормализацией
(`src/rugender/normalize.py`).

Приоритет при расхождении (`NAME_PRIORITY` в сборщике): ручной словарь → Татарстан →
Москва → Казахстан → Wikidata (люди) → Латвия → Литва → Азербайджан → Petrovich → Wikidata
(классы). Если два источника данных о реальном употреблении называют разный пол, имя
становится двуполым (u): пол решают отчество и фамилия.

Не используются: наборы под CC BY-SA (статистика ЗАГС на Hugging Face, russiannames,
Википедия, OpenCorpora) — несовместимы с закрытым продуктом; name-dataset — собран
из утечки персональных данных; наборы без указанной лицензии (Молдова, Армения,
Кыргызстан до 2024 г.).
