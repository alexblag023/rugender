# Казахстан — имена с полом

Выгружено 27.10.2026 из сервиса «Популярные имена» Бюро национальной статистики Агентства по стратегическому планированию и реформам РК (https://stat.gov.kz/ru/instuments/name/, API /api/srn/names/populars).

Условия использования (https://stat.gov.kz/ru/description/): данные можно использовать для любых целей, в том числе для создания программных продуктов, свободно и бесплатно, со ссылкой на источник. Изменения: имена с ≥5 носителями, суммирование по полу.
